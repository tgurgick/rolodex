## Usage for AI Agents

AI agents can:

1. **Parse** this Markdown to extract structured contact data
2. **Generate** new contact entries in this format
3. **Update** existing entries by modifying the Markdown
4. **Search** using natural language queries

### Example AI Queries

- "Find contacts at enterprise companies"
- "Who are the decision-makers I haven't contacted this week?"
- "List all contacts from referrals"
